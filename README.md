# BSS Durga Puja 2026 prototype

Static HTML/CSS/JS prototype for BSS Durga Puja 2026.

## Deploy to Vercel
1. Put all files in the repository root.
2. Import the GitHub repository into Vercel.
3. Select no framework / static site and deploy.

## Notes
- GA4 tracking hooks are included for `get_directions_click`, `whatsapp_click` and `schedule_view`.
- Final Pushpanjali, Bhog and evening timings are intentionally left as placeholders until BSS confirms them.
- Venue claims marked with an asterisk should be reconfirmed by the organisers before public launch.
- This prototype is not intended to replace the live site yet. Preserve existing SEO URLs and redirects during any production migration.
